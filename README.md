# Manejo de Colmenas

Sistema de gestión y control de colmenas apícolas.

## Características

- Panel de control interactivo
- Registro de inspecciones
- Seguimiento de producción
- Gestión de tareas
- Monitoreo de salud de colmenas

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm run dev
```

## Construcción

```bash
npm run build
```

## Tecnologías

- React + TypeScript
- Vite
- TailwindCSS
